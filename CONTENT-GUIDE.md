# Content Guide — Baral & K.C. Associates website

Who can change what, and how. No developer needed for Layers 1 and 2.

## Layer 1 — Partners & staff, from the browser (no code)

| Task | Where |
|---|---|
| Publish / edit / delete insights & tax alerts | `/admin` → Insights CMS |
| Update lead & consultation statuses | `/admin` → Leads & consultations |
| Review applications, download CVs | `/admin` → Applications |
| Export any table to CSV | `/admin` → relevant tab → Export CSV |
| Subscriber list | `/admin` → Subscribers |

Login: `/admin` with the firm admin account. Public sign-up is disabled.

## Layer 2 — Plain-text edits on GitHub (5-minute skill)

Open the file → pencil icon → edit words **inside the quotes** → Commit.
Vercel republishes in ~1 minute. Any mistake is revertible via commit history.

| What | File |
|---|---|
| Firm name, phone, email, address, hours, service names | `lib/site.js` |
| Service pages copy, FAQs, deliverables | `lib/services.js` |
| Industry dossiers | `lib/industries.js` |
| Job openings | `lib/jobs.js` |
| About-page facts, history, milestones, leadership | top of `app/about/page.js` |
| The six seeded insight notes | `lib/posts.js` |

### Safe-editing rules
1. Only change text between quotation marks.
2. Never delete commas, brackets or quotation marks.
3. One change, one commit, with a clear message (e.g. "update phone number").
4. To revise a seeded insight without touching code: publish a CMS note
   with the **same slug** — the CMS version replaces it everywhere.

## Layer 3 — Developer work
New pages, layout/design changes, new features (client portal, email
automation, payments). Contact the original build partner or any
Next.js developer; the codebase follows standard Next.js 14 + Tailwind
+ Supabase conventions.

## Technical notes
- Hosting: Vercel (auto-deploys on every commit to `main`).
- Database & auth & file storage: Supabase (tables, RLS policies, `resumes` bucket).
- Environment variables live in Vercel → Settings → Environment Variables
  (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
  `NEXT_PUBLIC_SITE_URL`). Never paste the Supabase `service_role` key anywhere.
- SEO: `/sitemap.xml` and `/robots.txt` are generated automatically;
  the social-share card is generated by `app/opengraph-image.js`.
